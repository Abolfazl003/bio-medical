## ✨ امکانات

### 🎒 دوره آموزش از پایه تا پیشرفته
برای کسانی که از صفر شروع می‌کنند. هر درس در **۳ سطح**:
- **سطح ۱ — پایه:** مفاهیم اولیه با زبان ساده، مثال‌های روزمره و تشبیه (مثل «برق مثل آب در لوله»)
- **سطح ۲ — متوسط:** وارد شدن به مباحث دانشگاهی
- **سطح ۳ — پیشرفته:** رسیدن به سطح واقعی کنکور ارشد

### 🏛 بانک کنکورهای ۱۰ سال اخیر (جدید در نسخه ۱.۲.۰)
سوالات **۱۰ دوره کنکور ارشد مهندسی پزشکی (۱۳۹۴ تا ۱۴۰۳)** — درس به درس:

- **۴۴۰ سوال** (۱۱ درس × ۴ سوال در هر سال)
- برای هر سوال: **۴ گزینه** + پاسخ صحیح + **راه‌حل کنکوری (ترفند سریع)** + **حل تشریحی کامل**
- مسیر: «کنکورهای ۱۰ سال اخیر» ← انتخاب سال ← انتخاب درس ← آزمون با تصحیح فوری (سبز/قرمز)
- **آزمون ترکیبی همه سال‌ها** (۲۰ سوال تصادفی از ۱۰ سال) و آزمون ترکیبی هر سال (۴۴ سوال)
- ذخیره سوال، ثبت نتیجه هر درس و نمایش درصد آخرین آزمون روی کارت درس

### 📕 ۱۰ کتاب درسی کامل
هر درس یک **کتاب کامل** دارد — نه خلاصه. متن درسی، فرمول‌ها، جدول‌ها و **مثال‌های حل‌شده گام‌به‌گام**:

| کتاب | فصل‌ها | زمان مطالعه |
|---|---|---|
| ریاضیات (معادلات دیفرانسیل، جبر خطی، آمار) | ۵ | ۲۵۵ دقیقه |
| مدارهای الکتریکی و الکترونیک | ۶ | ۲۹۵ دقیقه |
| سیگنال‌ها و سیستم‌ها | ۴ | ۲۰۵ دقیقه |
| آناتومی و فیزیولوژی | ۴ | ۲۰۰ دقیقه |
| فیزیک (الکتریسیته، مکانیک، موج، اپتیک) | ۴ | ۱۸۰ دقیقه |
| کنترل سیستم‌ها | ۶ | ۳۰۵ دقیقه |
| ابزار دقیق پزشکی | ۶ | ۳۱۵ دقیقه |
| بیومواد | ۶ | ۳۰۰ دقیقه |
| بیومکانیک | ۶ | ۳۱۰ دقیقه |
| تصویربرداری پزشکی | ۶ | ۳۲۵ دقیقه |

**جمع: ۱۰ کتاب • ۵۳ فصل • ۲٬۶۹۰ دقیقه (≈ ۴۵ ساعت) مطالعه • حدود ۴۳٬۵۰۰ کلمه**

امکانات کتاب‌خوان: فهرست مطالب، نوار پیشرفت، علامت «فصل خوانده شد»، دکمه «فصل بعدی»، جستجوی موضوعی و ذخیره خودکار پیشرفت.

### 📚 ۱۰ درس
ریاضیات، فیزیک، مدارهای الکتریکی و الکترونیک، سیگنال‌ها و سیستم‌ها، آناتومی و فیزیولوژی، بیومواد، بیومکانیک، ابزار دقیق پزشکی، تصویربرداری پزشکی، کنترل سیستم‌ها

### 📝 بانک سوال (۹۷ تست کنکوری)
هر سوال **دو توضیح** دارد:
- ⚡ **ترفند کنکوری:** چطور در ۱۰ ثانیه به جواب برسیم
- 📖 **حل کامل دانشگاهی:** توضیح علمی و پایه‌ای

همراه با **خروجی رنگی سبز/قرمز** لحظه‌ای و امکان **ذخیره سوال** برای مرور.

### ✏️ سوالات تمرینی تالیفی (۴۷ سوال)
سوالات غیرکنکوری برای مسلط شدن، با **کادر آموزش قبل از پاسخ** و حل تشریحی کامل. دو حالت: تمرین درس‌به‌درس یا ۱۵ سوال تصادفی ترکیبی.

### 🎓 آزمون‌های ۱۰ ساله
۱۰ آزمون واقعی (۱۳۹۴ تا ۱۴۰۳)، هر کدام ۲۵ سوال، با تایمر، تصحیح خودکار، کارنامه و درصدگیری مثل کنکور.

### 🧑‍🏫 استاد (تدریس خصوصی)
استاد مباحث را فعالانه درس می‌دهد، سوال می‌پرسد و اشتباهات را اصلاح می‌کند.

### 🔗 کتاب‌های رایگان
دسترسی به منابع معتبر و آزاد دانشگاهی (برای مطالعه شخصی).

### 💾 مدیریت پیشرفت
نشان‌گذاری دروس، ذخیره سوالات، گزارش درصد، پشتیبان‌گیری و بازگردانی، تم تاریک/روشن

## 🧩 ساختار پروژه

```
bme_konkur/
├── 📱 android/              ← پروژه کامل اندروید (WebView آفلاین)
│   └── app/src/main/
│       ├── assets/index.html        ← کل اپ در یک فایل
│       └── java/.../MainActivity.java  ← پل بومی (ذخیره، خروج، بازگشت)
├── 💻 desktop_app/          ← اپ دسکتاپ (pywebview)
│   ├── app.py
│   └── web/index.html
├── 🌐 web/                  ← نسخه وب + PWA
│   ├── index.html, style.css, app.js, data.js
│   ├── fonts/               ← فونت وزیرمتن (آفلاین)
│   ├── manifest.webmanifest, sw.js
│   └── icon-192.png, icon-512.png
├── 🐍 data/                 ← داده‌های نسخه پایتون
│   ├── subjects.py          ← ۱۰ درس، ۴۱ درس‌نامه
│   ├── questions.py         ← ۹۷ تست کنکوری
│   └── exams.py             ← ۱۰ آزمون
├── build_single.py          ← ساخت فایل تک‌صفحه‌ای آفلاین
├── main.py / app.py         ← نسخه دسکتاپ CustomTkinter
└── .github/workflows/       ← بیلد و انتشار خودکار
```

## 🛠️ ساخت نسخه‌ها

### ساخت فایل تک‌صفحه‌ای آفلاین
```bash
python build_single.py
# خروجی: bme-konkur-offline.html
```

### ساخت APK اندروید
```bash
cd android
gradle assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

### ساخت فایل اجرایی ویندوز
```bash
pip install pywebview pyinstaller
cd desktop_app
pyinstaller --windowed --onefile --add-data "web;web" app.py
```

### ساخت خودکار (GitHub Actions)
با هر تگ `v*` هر دو نسخه **اندروید و دسکتاپ** ساخته و به صورت خودکار در Releases منتشر می‌شوند:
```bash
git tag v1.0.0
git push origin v1.0.0
```
