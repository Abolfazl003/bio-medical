# 🩺 اپلیکیشن شخصی آمادگی کنکور ارشد مهندسی پزشکی (نسخه ۳.۰ — کامل)

## ✨ ویژگی‌های نسخه ۳.۰

### 🎒 دوره پایه تا پیشرفته (جدید!)
- تدریس **از صفرِ صفر**، با زبان خیلی ساده، انگار داری به یک بچه از ابتدا درس می‌دی
- سه سطح برای هر درس: **سطح ۱ پایه** (مفاهیم اولیه با تشبیه ساده مثل تشبیه الکتریسیته به آب) → **سطح ۲ متوسط** → **سطح ۳ پیشرفته/کنکور**
- درس‌ها تعاملی و گام‌به‌گام پیش می‌رن
- از دوره پایه مستقیم می‌تونی در انتهای درس بری سراغ تست زنی همان درس

### ✏️ سوالات تمرینی تالیفی (جدید!)
- **۴۷ سوال تمرینی** از کتاب‌های تمرین و کتاب کار (نه سوالات خود کنکور)
- مبحث به مبحث دسته‌بندی شده
- سطح سختی از پایه تا متوسط
- هر سوال:
  - 🎓 **کادر آموزشی قبل از جواب**: یک درس کوچیک توی خود سوال بهت میده که نکته اصلی رو یاد بگیری
  - پاسخ کاملاً سبز/قرمز فوری
  - 📚 جواب تشریحی کامل

### قابلیت‌های قبلی که نگه داشته شد:
- 🎲 تست ترکیبی مبحثی شافل هوشمند (هر بار جدید)
- ✅ رنگی شدن فوری درست/غلط
- 🎯 راه حل کنکوری + 📚 توضیح کامل برای هر سوال کنکور
- 💾 دکمه ذخیره سوال برای مرور بعدی
- 🧑‍🏫 استاد (تدریس نکته‌وار و نکات تستی کنکور)
- 🔗 لینک کتاب‌های رایگان قانونی و آزاد
- 📖 ۲۰ کتاب مرجع اصلی
- 🎓 ۱۰ دوره آزمون ۱۳۹۴–۱۴۰۳ با تایمر
- ⭐ نشان‌کردن، آمار، تم تاریک/روشن، پشتیبان

## ▶️ اجرا

### 🪟 روی ویندوز (ساده‌ترین روش):
فقط روی **`run.bat`** دابل‌کلیک کن!
- به طور خودکار پایتون رو چک می‌کنه
- میره سراغ نسخه وب (که تمام امکانات داره)
- سرور رو روی پورت ۸۰۰۰ بالا میاره
- خودش مرورگر رو باز می‌کنه
کاره دیگه‌ای لازم نیست انجام بدی.

اگر می‌خوای **نسخه دسکتاپ** (پنجره جدا) رو اجرا کنی، روی **`run_desktop.bat`** دابل‌کلیک کن. اگه customtkinter نداشته باشی خودش نصب می‌کنه؛ اگه به هر دلیلی اجرا نشد به صورت خودکار نسخه وب رو بالا میاره.

### 🍎 روی macOS / 🐧 روی لینوکس:
روی **`run.command`** دابل‌کلیک کن (یا با ترمینال `./run.command` بزن).
به طور خودکار مرورگر باز میشه و سرور بالا میاد.

### راه اندازی دستی (همه پلتفرم‌ها):
```bash
cd web
python3 -m http.server 8000
# مرورگر: http://localhost:8000
```

نسخه دسکتاپ پایتون:
```bash
pip install customtkinter pillow
python main.py
```
