## ✨ امکانات

### 🎒 دوره آموزش از پایه تا پیشرفته
برای کسانی که از صفر شروع می‌کنند. هر درس در **۳ سطح**:
- **سطح ۱ — پایه:** مفاهیم اولیه با زبان ساده، مثال‌های روزمره و تشبیه (مثل «برق مثل آب در لوله»)
- **سطح ۲ — متوسط:** وارد شدن به مباحث دانشگاهی
- **سطح ۳ — پیشرفته:** رسیدن به سطح واقعی کنکور ارشد

### 🏛 بانک کنکورهای ۱۰ سال اخیر
سوالات **۱۰ دوره کنکور ارشد مهندسی پزشکی (۱۳۹۴ تا ۱۴۰۳)** — درس به درس:

- **۴۴۰ سوال** (۱۱ درس × ۴ سوال در هر سال)
- برای هر سوال: **۴ گزینه** + پاسخ صحیح + **راه‌حل کنکوری (ترفند سریع)** + **حل تشریحی کامل**
- مسیر: «کنکورهای ۱۰ سال اخیر» ← انتخاب سال ← انتخاب درس ← آزمون با تصحیح فوری (سبز/قرمز)
- **آزمون ترکیبی همه سال‌ها** (۲۰ سوال تصادفی از ۱۰ سال) و آزمون ترکیبی هر سال (۴۴ سوال)
- ذخیره سوال، ثبت نتیجه هر درس و نمایش درصد آخرین آزمون روی کارت درس

### 📚 ۴۱ کتاب درسی کامل — چند کتاب برای هر مبحث (جدید در نسخه ۱.۳.۰)
دیگر «یک کتاب برای هر درس» نیست: برای **هر مبحث چند کتاب مستقل** با **آزمون اختصاصی خودش**:

| درس | کتاب‌ها | فصل‌ها | دقیقه مطالعه |
|---|---|---|---|
| ریاضیات | ۵ کتاب | ۶ | ۳۱۰ |
| فیزیک | ۴ کتاب | ۵ | ۲۳۵ |
| مدارها و الکترونیک | ۵ کتاب | ۸ | ۴۰۰ |
| سیگنال‌ها و سیستم‌ها | ۴ کتاب | ۶ | ۲۹۰ |
| کنترل سیستم‌ها | ۴ کتاب | ۷ | ۳۶۵ |
| ابزار دقیق پزشکی | ۴ کتاب | ۷ | ۳۷۰ |
| تصویربرداری پزشکی | ۵ کتاب | ۷ | ۳۸۰ |
| بیومواد | ۳ کتاب | ۶ | ۳۱۰ |
| بیومکانیک | ۳ کتاب | ۶ | ۲۸۵ |
| آناتومی و فیزیولوژی | ۴ کتاب | ۵ | ۲۴۰ |

- **جمعاً ۴۱ کتاب، ۶۲ فصل، حدود ۵۳ ساعت مطالعه و بیش از ۵۰٬۰۰۰ کلمه متن درسی**
- **۲۴۶ سؤال اختصاصی کتاب‌ها** (۶ سؤال برای هر کتاب) + **تست فصل‌به‌فصل** برای ۶۱ فصل
- صفحه اختصاصی هر کتاب: فهرست، پیشرفت مستقل، «کلاس استاد این کتاب»، «جزوه» و «آزمون این کتاب»
- امکانات کتاب‌خوان: فهرست کنار صفحه، نوار پیشرفت، علامت «فصل خوانده شد» و دکمه «فصل بعدی»

### 🖼 شکل‌ها و مدارهای تصویری واقعی (جدید در نسخه ۱.۳.۰)
**۴۷ شکل برداری واقعی (SVG)** — نه شکل شماتیک متنی:
- **۱۲ نمودار** با محور، شبکه و منحنی واقعی: پاسخ پله، بود و حاشیه فاز، ریشه‌مکان، ECG، پتانسیل عمل، حلقه فشار-حجم، اشباع هموگلوبین، توزیع نرمال، بازیافت T1/T2، PPG، سری فوریه، سرعت هدایت عصبی
- **۱۶ مدار استاندارد** با نمادهای درست: سری/موازی، KCL، تحلیل مش، تقسیم‌کننده ولتاژ، تونن، پل وتستون، RC، RLC، فیلتر پایین‌گذر، دیود، یک‌سوساز، ترانزیستور امیتر مشترک، آپ‌امپ معکوس/غیرمعکوس، تقویت‌کننده ابزار دقیق
- **۹ شکل آناتومی و فیزیولوژی:** قلب، نفرون، آلوئول، نورون و سیناپس، گوش، چشم، سارکومر، عروق، مسیر تحریک قلب
- **۳ بلوک‌دیاگرام:** سیستم بازخورد، زنجیره پردازش سیگنال زیستی، کنترل‌کننده PID — و **۵ شکل تصویربرداری**
- **موتور چیدمان خودکار:** هر شکل قبل از نمایش بازبینی می‌شود تا هیچ متنی روی متن دیگر نیفتد و از کادر بیرون نزند

### 🧑‍🏫 کلاس کامل استاد — از روی کتاب، فصل‌به‌فصل (جدید در نسخه ۱.۳.۰)
استاد **کل متن کتاب‌ها را تدریس می‌کند**، نه خلاصه:
- **بیش از ۱٬۲۰۰ بخش کلاس:** برای هر فصل — مقدمه، تدریس کامل همه پاراگراف‌ها، همه فرمول‌ها («این فرمول را با خودکار قرمز در جزوه‌ات بنویس…»)، مثال‌های حل‌شده گام‌به‌گام، شکل‌ها، دام‌های آزمون و جمع‌بندی
- پایان هر فصل: یادآوری دقیقه‌های مطالعه + پیشنهاد مستقیم «تست همین فصل»
- «کل درس» = همه کتاب‌های آن درس پشت سر هم (نمونه: ریاضیات ۱۰۱ بخش، مدارها ۱۱۰ بخش)

### 📝 جزوه اختصاصی هر استاد (جدید در نسخه ۱.۳.۰)
از دل محتوای همه کتاب‌ها، **جزوه کاربردی و قابل چاپ** ساخته می‌شود:
- ۹ بخش: چکیده استاد، نقشه راه، **بانک فرمول**، **نکته/دام/ترفند کنکوری**، **جدول‌های مرجع**، مثال‌های شاخص، خلاصه فصل‌به‌فصل، پرسش‌های کلیدی آزمون، چک‌لیست مرور
- «جزوه جامع درس» = ادغام همه کتاب‌های آن درس در یک جزوه
- دکمه **چاپ / ذخیره PDF** با استایل چاپ سفید و خوانا + پرش مستقیم به آزمون کتاب

### ⏱ زمان مطالعه و برنامه‌ریزی شخصی (جدید در نسخه ۱.۳.۰)
- **چقدر خوانده‌ام:** با تیک‌زدن هر فصل، دقیقه‌های مطالعه ثبت می‌شود (و پیشرفت قبلی‌ات هم یک‌بار محاسبه می‌شود)
- **چقدر مانده:** کل برنامه = ۵۳ ساعت کتاب + بانک کنکور (مجموعاً حدود ۷۵ ساعت)
- **چند روز دیگر تمام می‌شود:** بر اساس هدف روزانه (۳۰/۴۴/۶۰/۹۰/۱۲۰ دقیقه)؛ اگر عقب باشی می‌گوید روزی چند دقیقه لازم داری
- **نمودار ۱۴ روز اخیر**، **تقویم مطالعه ۵ هفته**، میانگین روزانه، روزهای فعال و **پیشرفت به تفکیک هر درس**
- روزشمار پویا تا کنکور ارشد بعدی

### 📚 ۱۰ درس (۱۱ درس با کنکور)
ریاضیات، فیزیک، مدارهای الکتریکی و الکترونیک، سیگنال‌ها و سیستم‌ها، آناتومی و فیزیولوژی، بیومواد، بیومکانیک، ابزار دقیق پزشکی، تصویربرداری پزشکی، کنترل سیستم‌ها

### 📝 بانک سوال (۹۷ تست کنکوری)
هر سوال **دو توضیح** دارد:
- ⚡ **ترفند کنکوری:** چطور در ۱۰ ثانیه به جواب برسیم
- 📖 **حل کامل دانشگاهی:** توضیح علمی و پایه‌ای

همراه با **خروجی رنگی سبز/قرمز** لحظه‌ای و امکان **ذخیره سوال** برای مرور.

### ✏️ سوالات تمرینی تالیفی (۴۷ سوال)
سوالات غیرکنکوری برای مسلط شدن، با **کادر آموزش قبل از پاسخ** و حل تشریحی کامل. دو حالت: تمرین درس‌به‌درس یا ۱۵ سوال تصادفی ترکیبی.

### 🎓 آزمون‌های ۱۰ ساله
۱۰ آزمون واقعی (۱۳۹۴ تا ۱۴۰۳)، هر کدام ۲۵ سوال، با تایمر، تصحیح خودکار، کارنامه و درصدگیری مثل کنکور.

### 🧑‍🏫 استاد (تدریس خصوصی)
کلاس کتاب‌به‌کتاب و فصل‌به‌فصل: استاد متن کتاب را باز می‌کند، فرمول‌ها را می‌نویسد، مثال‌ها را قدم‌به‌قدم حل می‌کند و دام‌های آزمون را می‌گوید — همراه با جزوه هر درس.

### 🔗 کتاب‌های رایگان
دسترسی به منابع معتبر و آزاد دانشگاهی (برای مطالعه شخصی).

### 💾 مدیریت پیشرفت
نشان‌گذاری دروس، ذخیره سوالات، گزارش درصد، پشتیبان‌گیری و بازگردانی، تم تاریک/روشن

│   ├── index.html, style.css, app.js, data.js
│   ├── fonts/               ← فونت وزیرمتن (آفلاین)

│   ├── questions.py         ← ۹۷ تست کنکوری

## 🛠️ ساخت نسخه‌ها

### ساخت فایل تک‌صفحه‌ای آفلاین
```bash
python build_single.py
# خروجی: bme-konkur-offline.html
```

### ساخت APK اندروید
```bash
cd android
gradle assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

### ساخت فایل اجرایی ویندوز
```bash
pip install pywebview pyinstaller
cd desktop_app
pyinstaller --windowed --onefile --add-data "web;web" app.py
```

### ساخت خودکار (GitHub Actions)
با هر تگ `v*` هر دو نسخه **اندروید و دسکتاپ** ساخته و به صورت خودکار در Releases منتشر می‌شوند:
```bash
git tag v1.0.0
git push origin v1.0.0
```
