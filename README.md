## ✨ امکانات

### 🎒 دوره آموزش از پایه تا پیشرفته
برای کسانی که از صفر شروع می‌کنند. هر درس در **۳ سطح**:
- **سطح ۱ — پایه:** مفاهیم اولیه با زبان ساده، مثال‌های روزمره و تشبیه (مثل «برق مثل آب در لوله»)
- **سطح ۲ — متوسط:** وارد شدن به مباحث دانشگاهی
- **سطح ۳ — پیشرفته:** رسیدن به سطح واقعی کنکور ارشد

### 🎯 کنکور آزمایشی — ۱۲۰۰ سوال، ۱۰ سال (شبیه‌ساز کامل کنکور)

دو بخش جدا در اپ وجود دارد (هیچ سوالی حذف نشده — همه ۱۲۰۰ سوال به این بخش منتقل شده‌اند):

**۱) 🎯 کنکور آزمایشی** — همه سوالات بانک ۱۰ ساله (**۱۳۹۴ تا ۱۴۰۳**)، درس به درس:

- **۱۲۰۰ سوال — هر سال ۱۲۰ سوال دقیقاً مثل کنکور واقعی** (۱۵ ریاضی + ۱۵ فیزیک + ۹ درس تخصصی × ۱۰ سوال)
- برای هر سوال: **۴ گزینه** + پاسخ صحیح + **راه‌حل کنکوری (ترفند سریع)** + **حل تشریحی کامل**
- مسیر: «آزمایشی» ← انتخاب سال ← انتخاب درس ← آزمون با تصحیح فوری (سبز/قرمز)
- **آزمون ترکیبی همه سال‌ها** (۲۰ سوال تصادفی از ۱۰ سال) و آزمون ترکیبی هر سال (۱۲۰ سوال)
- ذخیره سوال، ثبت نتیجه هر درس و نمایش درصد آخرین آزمون روی کارت درس

**۲) 🏛 کنکور (سوالات رسمی)** — **۱۸ دوره دفترچه رسمی وزارت بهداشت: ۱۳۸۷ تا ۱۴۰۴**، با شماره سوال اصلی و گزینه‌های دقیق؛
هر آزمون با **زمان واقعی همان دفترچه** برگزار می‌شود (۱۶۰ دقیقه؛ سال ۱۳۸۷: ۱۵۰ دقیقه).
تعداد سوال هر سال از روی جلد خود دفترچه خوانده شده است: ۱۳۸۷ → ۱۱۰، ۱۳۸۸ تا ۱۳۹۵ و ۱۳۹۸-۹۹ → ۱۳۰، ۱۳۹۶ → ۱۳۵، ۱۳۹۷ → ۱۴۰ و ۱۴۰۰ به بعد → ۱۲۰ سوال (جمعاً ۲۱۶۵ سوال از ۱۷ دفترچه).
۱۷ دفترچه در اختیار است و فقط دفترچه **۱۴۰۲** باقی مانده. کلید رسمی سنجش داخل دفترچه‌ها چاپ نشده، بنابراین پاسخ‌ها با عنوان **«حل مؤلف (غیررسمی)»** ارائه و پس از دریافت کلید رسمی جایگزین می‌شوند.
متن دفترچه‌ها هم بدون حذف سوالات بانک، در همین بخش درج خواهد شد.

### ⏱ حالت آزمون واقعی — تایمر ۱۶۰ دقیقه‌ای (جدید در نسخه ۱.۳.۲)

همان شرایط جلسه کنکور: **۱۲۰ سوال در ۱۶۰ دقیقه** (۸۰ ثانیه برای هر سوال).

- روی صفحه «کنکور» یا صفحه هر سال، دکمه **«⏱ حالت آزمون واقعی»** را روشن کن
- شمارش معکوس بالای آزمون نمایش داده می‌شود و در ۱۰ دقیقه آخر **قرمز و چشمک‌زن** می‌شود
- با تمام شدن زمان، آزمون **خودکار تصحیح** می‌شود
- در پایان، **کارنامه زمان** می‌گیری: زمان کل، زمان صرف‌شده، میانگین هر سوال و
  **جدول زمان هر درس** (تعداد سوال، زمان، میانگین ثانیه بر سوال با مقایسه با هدف ۸۰ ثانیه)

### 🖼 شکل‌ها و مدارهای تصویری واقعی (جدید در نسخه ۱.۳.۰)
**۴۷ شکل برداری واقعی (SVG)** — نه شکل شماتیک متنی:
- **۱۲ نمودار** با محور، شبکه و منحنی واقعی: پاسخ پله، بود و حاشیه فاز، ریشه‌مکان، ECG، پتانسیل عمل، حلقه فشار-حجم، اشباع هموگلوبین، توزیع نرمال، بازیافت T1/T2، PPG، سری فوریه، سرعت هدایت عصبی
- **۱۶ مدار استاندارد** با نمادهای درست: سری/موازی، KCL، تحلیل مش، تقسیم‌کننده ولتاژ، تونن، پل وتستون، RC، RLC، فیلتر پایین‌گذر، دیود، یک‌سوساز، ترانزیستور امیتر مشترک، آپ‌امپ معکوس/غیرمعکوس، تقویت‌کننده ابزار دقیق
- **۹ شکل آناتومی و فیزیولوژی:** قلب، نفرون، آلوئول، نورون و سیناپس، گوش، چشم، سارکومر، عروق، مسیر تحریک قلب
- **۳ بلوک‌دیاگرام:** سیستم بازخورد، زنجیره پردازش سیگنال زیستی، کنترل‌کننده PID — و **۵ شکل تصویربرداری**
- **موتور چیدمان خودکار:** هر شکل قبل از نمایش بازبینی می‌شود تا هیچ متنی روی متن دیگر نیفتد و از کادر بیرون نزند

## 🛠️ ساخت نسخه‌ها

### ساخت فایل تک‌صفحه‌ای آفلاین
```bash
python build_single.py
# خروجی: bme-konkur-offline.html
```

### ساخت APK اندروید
```bash
cd android
gradle assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

### ساخت فایل اجرایی ویندوز
```bash
pip install pywebview pyinstaller
cd desktop_app
pyinstaller --windowed --onefile --add-data "web;web" app.py
```

### ساخت خودکار (GitHub Actions)
با هر تگ `v*` هر دو نسخه **اندروید و دسکتاپ** ساخته و به صورت خودکار در Releases منتشر می‌شوند:
```bash
git tag v1.0.0
git push origin v1.0.0
```
